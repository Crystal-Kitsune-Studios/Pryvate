# Pryvate 🦊

An early-stage privacy project from Crystal Kitsune Studios.

- **[Pip](pip-bot/)** is a consent-first, self-hostable CLI prototype that searches for possible public data-broker listings and helps people find official opt-out routes. Searches rely on a local SearXNG instance and its upstream engines. Pip does not automatically remove listings or send requests. See the [Pip README](pip-bot/README.md) for setup, limitations, and privacy guidance.
- **[Website](website/)** is a browser-only prototype for drafting deletion requests. Open `website/index.html` to use it locally. Requests must be reviewed and sent by the user.

These are prototypes, not legal advice. Only search for your own information or with the person's permission.
